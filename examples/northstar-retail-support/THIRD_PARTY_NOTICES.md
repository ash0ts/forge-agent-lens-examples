## τ³-bench / tau2-bench

The bundled retail database, policy, and tool contracts derive from
[`sierra-research/tau2-bench`](https://github.com/sierra-research/tau2-bench),
version 1.0.1. The repository pins the annotated tag and its peeled source
commit in `source.lock.json`, then deterministically replaces fictional
identities before execution. Benchmark task truth and run artifacts are not
included in this repository.
